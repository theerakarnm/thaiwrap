**Goal:** Ship thaiwrap 0.2.0: Thai Character Cluster splitting for long words, a Thai-only ICU data blob, a gated UTF-16 path in the binding, two gated new exports, and the core crate on crates.io as `thaiwrap`.
**Architecture:** All logic stays in `crates/thaiwrap-core`; the napi binding only converts and validates.
The ICU4X segmenters move from compiled data to a committed postcard blob loaded with `icu_provider_blob` (no `unsafe` in our crates).
Performance-gated work (UTF-16 strings in the binding, `wrapThaiBatch`, `wrapThaiRanges`) is measured with one committed harness before it is merged, and a failed gate leaves only a results document behind.
**Tech Stack:** Rust 1.99.0 (MSRV 1.88), `icu_segmenter =2.4.0`, `icu_provider_blob =2.4.0`, napi-rs 3 (`napi 3.16.1`, `napi4`), Node 22/24, Bun 1.4.4, release-please, crates.io trusted publishing.
**Spec:** none - planned from conversation (the user's answers of 2026-10-31 to six v0.2 questions; quoted in `## Decisions`).
**Base commit:** `7083513` (`main`, = `origin/main`, v0.1.0 released).
**Confidence:** 10/10 by the rubric (0 deductions, see `## Confidence`) - not captured by the rubric: three of the four performance gates look likely to fail (see `### Measured outlook for the gates`), and D6, D11, D14, D18, D20 need the user's yes at plan review.

**NOT building:**
- `keepTogether` word list (v0.3, issue #1).
- Any change to the Thai text rules, including `ๅ` (U+0E45 lakkhangyao): `thai::is_no_line_start` (`crates/thaiwrap-core/src/thai.rs:17-22`) does not list it, so v0.1 and TCC can both cut `ฤ|ๅ`; changing it is a Thai-rules decision for a later release.
- A new `overflow` value: TCC replaces what `"split"` does (user, answer 2).
- Lao, Khmer and Burmese dictionaries: dropped on purpose, documented as unsupported scripts (user, answer 1).
- Baked ICU data (contains `unsafe`) and the spike branch `spike/icu-data-size` code (only its sample files are reused).
- `wrapThaiRanges` returning `Array<[number, number]>` (user, answer 4: flat `Uint32Array` only).
- Publishing anything from an agent: no `npm publish`, `cargo publish`, `cargo login`, tags, or release-PR merges.
- A JS-side ranges or batch API if its gate fails; a UTF-16 path if its gate fails.
- A UTF-16 path inside the core (`wrap_utf16`, a generic core): Phase 3 tries the binding-only variant (D11); a core variant needs a new decision.
- Renaming the directory `crates/thaiwrap-core` (user, answer 5: only the package name changes).
- Re-reviewing the 916 v0.1 parity entries (separate open item; Task 5 re-baselines them mechanically).

Why (round 2): most of the time is in the core, not at the JS boundary. Pure Rust `short` takes 1.82 us (docs/m0/benchmarks.md:26) and the JS call about 3.2 us, and a napi call costs well under 1 us, so batching cannot save 20%.
A core-level UTF-16 path would add little: ICU4X's dictionary segmenter works on `str` natively (`icu_segmenter-2.4.0/src/complex/dictionary.rs:139-171`), so only the binding's decode pass would go away.
The gate tasks run the gate before writing tests or docs, so a FAIL costs one build and one record.

<!-- SOURCE: crates/thaiwrap-node/src/lib.rs:52-63 -->
```rust
fn read_string(env: &Env, value: &Unknown<'_>, name: &str) -> Result<String> {
    if value.get_type()? != ValueType::String {
        return Err(type_error(
            env,
            &format!("{name} must be a string, got {}", type_name(value)),
        ));
    }
    // Lossy on purpose: lone surrogates become U+FFFD (see README Known limitations), whatever bytes the runtime's
    // napi_get_value_string_utf8 produces for them (runtimes may differ).
    let utf8 = value.coerce_to_string()?.into_utf8()?;
    Ok(String::from_utf8_lossy(utf8.as_slice()).into_owned())
}
```

      //! Thai Character Cluster (TCC) boundaries: the smallest groups of Thai characters that should
      //! never be split. For example `เกี่ยว` is `เกี่ย` + `ว`, so an overflow cut may fall only
      //! after `เกี่ย`, never inside it.
      //!
      //! The rules come from Theeramunkong, Sornlertlamvanich, Tanhermhong and Chinnan, "Character
      //! cluster based Thai information retrieval", IRAL 2000, ACM, pp. 75-80,
      //! doi:10.1145/355214.355225. The rule list and its order are ported from `PyThaiNLP` 5.4.0
      //! `pythainlp/tokenize/tcc_p.py` (tag v5.4.0, commit 7f26adf5ce09c3d77c39ca2ef86f7138e9071088,
      //! Apache-2.0), where the first rule that matches wins. `__test__/tcc.mjs` is a regex port of
      //! the same file; the tests below compare against the fixtures it writes.

      use crate::thai;

      /// A character class in a TCC rule.
      #[derive(Clone, Copy)]
      enum Class {
          /// A Thai consonant ก-ฮ (U+0E01-U+0E2E). It includes ฤ and ฦ and excludes ฯ.
          Consonant,
          /// A tone mark ่ ้ ๊ ๋ (U+0E48-U+0E4B).
          Tone,
          /// A leading vowel เ แ โ ใ ไ (U+0E40-U+0E44).
          Leading,
          /// ะ to ู (U+0E30-U+0E39), the `[ะ-ู]` range of rule 15.
          Vowel,
          /// One of the listed characters.
          Any(&'static [char]),
      }

      impl Class {
          fn has(self, c: char) -> bool {
              match self {
                  Self::Consonant => matches!(c, '\u{0E01}'..='\u{0E2E}'),
                  Self::Tone => matches!(c, '\u{0E48}'..='\u{0E4B}'),
                  Self::Leading => thai::is_leading_vowel(c),
                  Self::Vowel => matches!(c, '\u{0E30}'..='\u{0E39}'),
                  Self::Any(set) => set.contains(&c),
              }
          }
      }

      /// One step of a rule.
      #[derive(Clone, Copy)]
      enum Step {
          One(Class),
          /// Optional and greedy, like regex `x?`.
          Opt(Class),
          /// The optional silent final that `tcc_p.py` writes as `k`, `(cc?[ุูิ]?์)?`: a consonant
          /// cancelled by ์ (การันต์), as in `สินทร์` = `สิ` + `นทร์`.
          Silent,
          /// Zero width: the next character is a consonant or a leading vowel, or the text ends.
          Ahead,
      }

      use Step::{Ahead, Opt, Silent};

      const C: Step = Step::One(Class::Consonant);
      const T: Step = Opt(Class::Tone);
      const fn ch(set: &'static [char]) -> Step {
          Step::One(Class::Any(set))
      }
      const fn opt(set: &'static [char]) -> Step {
          Opt(Class::Any(set))
      }

      /// `tcc_p.py` `_RE_TCC`, in order; the comment is the original pattern.
      const RULES: [&[Step]; 29] = [
          &[ch(&['เ']), C, ch(&['็']), C, Silent],                                // เc็ck
          &[ch(&['เ']), C, C, T, ch(&['า']), ch(&['ะ']), Silent],                 // เcctาะk
          &[ch(&['เ']), C, C, ch(&['ี']), T, ch(&['ย']), ch(&['ะ']), Silent],     // เccีtยะk
          &[ch(&['เ']), C, C, ch(&['ี']), T, ch(&['ย']), Ahead, Silent],          // เccีtย(?=[เ-ไก-ฮ]|$)k
          &[ch(&['เ']), C, C, ch(&['็']), C, Silent],                             // เcc็ck
          &[ch(&['เ']), C, ch(&['ิ']), C, ch(&['์']), C, Silent],                 // เcิc์ck
          &[ch(&['เ']), C, ch(&['ิ']), T, C, Silent],                             // เcิtck
          &[ch(&['เ']), C, ch(&['ี']), T, ch(&['ย']), opt(&['ะ']), Silent],       // เcีtยะ?k
          &[ch(&['เ']), C, ch(&['ื']), T, ch(&['อ']), opt(&['ะ']), Silent],       // เcืtอะ?k
          &[ch(&['เ']), C, ch(&['ิ', 'ี', 'ุ', 'ู']), T, ch(&['ย']), Ahead, Silent], // เc[ิีุู]tย(?=[เ-ไก-ฮ]|$)k
          &[ch(&['เ']), C, T, opt(&['า']), opt(&['ะ']), Silent],                  // เctา?ะ?k
          &[C, ch(&['ั']), T, ch(&['ว']), ch(&['ะ']), Silent],                    // cัtวะk
          &[C, ch(&['ั', 'ื']), T, C, opt(&['ุ', 'ิ', 'ะ']), Silent],             // c[ัื]tc[ุิะ]?k
          &[C, ch(&['ิ', 'ุ', 'ู']), ch(&['์'])],                                  // c[ิุู]์
          &[C, Step::One(Class::Vowel), T, Silent],                                // c[ะ-ู]tk
          &[C, ch(&['ร']), ch(&['ร']), C, ch(&['์'])],                             // cรรc์
          &[C, ch(&['็'])],                                                        // c็
          &[C, T, opt(&['ะ', 'า', 'ำ']), Silent],                                  // ct[ะาำ]?k
          &[C, Silent],                                                            // ck
          &[ch(&['แ']), C, ch(&['็']), C],                                         // แc็c
          &[ch(&['แ']), C, C, ch(&['์'])],                                         // แcc์
          &[ch(&['แ']), C, T, ch(&['ะ'])],                                         // แctะ
          &[ch(&['แ']), C, C, ch(&['็']), C],                                      // แcc็c
          &[ch(&['แ']), C, C, C, ch(&['์'])],                                      // แccc์
          &[ch(&['โ']), C, T, ch(&['ะ'])],                                         // โctะ
          &[Step::One(Class::Leading), C, T],                                      // [เ-ไ]ct
          &[ch(&['ก']), ch(&['็'])],                                               // ก็
          &[ch(&['อ']), ch(&['ึ'])],                                               // อึ
          &[ch(&['ห']), ch(&['ึ'])],                                               // หึ
      ];

      const LOWER_OR_I: &[char] = &['ุ', 'ู', 'ิ'];
      /// The shapes of `Silent`, in the order a backtracking regex tries them.
      const SILENT: [&[Step]; 4] = [
          &[C, C, ch(LOWER_OR_I), ch(&['์'])],
          &[C, C, ch(&['์'])],
          &[C, ch(LOWER_OR_I), ch(&['์'])],
          &[C, ch(&['์'])],
      ];

      /// Number of characters `rule` matches at the start of `chars`.
      fn match_rule(chars: &[char], rule: &[Step]) -> Option<usize> {
          let Some((step, rest)) = rule.split_first() else {
              return Some(0);
          };
          let first = chars.first().copied();
          let then = |n: usize| {
              chars
                  .get(n..)
                  .and_then(|tail| match_rule(tail, rest))
                  .map(|m| m + n)
          };
          match *step {
              Step::One(class) => first.filter(|&c| class.has(c)).and_then(|_| then(1)),
              Opt(class) => first
                  .filter(|&c| class.has(c))
                  .and_then(|_| then(1))
                  .or_else(|| match_rule(chars, rest)),
              Silent => SILENT
                  .iter()
                  .find_map(|shape| match_rule(chars, shape).and_then(then))
                  .or_else(|| match_rule(chars, rest)),
              Ahead => first
                  .is_none_or(|c| Class::Consonant.has(c) || Class::Leading.has(c))
                  .then(|| match_rule(chars, rest))
                  .flatten(),
          }
      }

      /// TCC cluster ends of `text` as byte offsets, ascending; the last one is `text.len()`.
      /// A character that no rule matches (for example a Latin letter, a digit, or ๆ) is a cluster
      /// on its own.
      pub(crate) fn cluster_ends(text: &str) -> Vec<usize> {
          let chars: Vec<char> = text.chars().collect();
          let mut ends = Vec::new();
          let mut rest = chars.as_slice();
          let mut end = 0usize;
          while !rest.is_empty() {
              // Every rule starts with a required character, so a match is never empty.
              let n = RULES
                  .iter()
                  .find_map(|rule| match_rule(rest, rule))
                  .unwrap_or(1)
                  .max(1);
              let Some((cluster, tail)) = rest.split_at_checked(n) else {
                  break;
              };
              end = cluster.iter().fold(end, |e, c| e.saturating_add(c.len_utf8()));
              ends.push(end);
              rest = tail;
          }
          ends
      }
      ```

          /// ends (see `tcc`), so `เกี่ยว` can be cut as `เกี่ย` + `ว` but never as `เกี่` + `ยว`.
          /// Every cut is also a grapheme boundary allowed by the Thai rules. A piece between two
          /// such cuts that is still longer than `max_length` falls back to all grapheme cuts inside
          /// it, and a piece with no legal cut at all stays whole.
          fn split_overflow(&self, content: Range<usize>) -> Vec<Line> {
              let text = self.text;
              let Some(word) = text.get(content.clone()) else {
                  return Vec::new();
              };
              let graphemes: Vec<usize> = segment::grapheme_boundaries(word)
                  .map(|b| content.start + b)
                  .filter(|&b| b > content.start && b < content.end && thai::allowed(text, b))
                  .collect();
              let cluster_cuts = tcc::cluster_ends(word)
                  .into_iter()
                  .map(|b| content.start + b)
                  .filter(|b| graphemes.binary_search(b).is_ok())
                  .chain(std::iter::once(content.end));
              let mut cuts = Vec::with_capacity(graphemes.len() + 1);
              let mut piece_start = content.start;
              for end in cluster_cuts {
                  if self.measure(piece_start..end) > self.max_length {
                      let from = graphemes.partition_point(|&g| g <= piece_start);
                      let to = graphemes.partition_point(|&g| g < end);
                      cuts.extend(graphemes.get(from..to).unwrap_or_default());
                  }
                  cuts.push(end);
                  piece_start = end;
              }
              let mut chunks: Vec<Line> = Vec::new();
              let mut piece_start = content.start;
              for cut in cuts {
                  let width = self.measure(piece_start..cut);
                  match chunks.last_mut() {
                      Some(chunk) if chunk.len.saturating_add(width) <= self.max_length => {
                          chunk.range.end = cut;
                          chunk.len = chunk.len.saturating_add(width);
                      }
                      _ => chunks.push(Line {
                          range: piece_start..cut,
                          len: width,
                      }),
                  }
                  piece_start = cut;
              }
              chunks
          }

      /// Reads a JS string as UTF-16 code units, without the UTF-8 conversion, so lone surrogates stay.
      fn read_utf16<'a>(env: &Env, value: &'a Unknown<'_>, name: &str) -> Result<JsStringUtf16<'a>> {
          if value.get_type()? != ValueType::String {
              return Err(type_error(env, &format!("{name} must be a string, got {}", type_name(value))));
          }
          value.coerce_to_string()?.into_utf16()
      }

      /// Turns ascending UTF-8 byte ranges of `text` into flat UTF-16 offsets
      /// `[start0, end0, start1, end1, ...]` in one forward pass.
      fn utf16_offsets(text: &str, ranges: &[std::ops::Range<usize>]) -> Result<Vec<u32>> {
          let mut out = Vec::with_capacity(ranges.len().saturating_mul(2));
          let mut chars = text.char_indices().peekable();
          let mut unit = 0usize;
          for pos in ranges.iter().flat_map(|r| [r.start, r.end]) {
              while let Some((_, c)) = chars.next_if(|&(i, _)| i < pos) {
                  unit = unit.saturating_add(c.len_utf16());
              }
              out.push(u32::try_from(unit).map_err(|_| internal_error("an offset does not fit in 32 bits"))?);
          }
          Ok(out)
      }

      /// One text: decode once for the core (a lone surrogate becomes U+FFFD, still one UTF-16
      /// unit, so lengths do not change), then cut the lines from the original UTF-16 units so
      /// lone surrogates come back out unchanged.
      fn wrap_text_value(
          env: &Env,
          value: &Unknown<'_>,
          name: &str,
          max_length: usize,
          options: &thaiwrap_core::WrapOptions,
      ) -> Result<Vec<Utf16String>> {
          let js = read_utf16(env, value, name)?;
          // napi's UTF-16 buffer ends with a NUL that is not part of the string.
          let units = js.as_slice().split_last().map_or(&[][..], |(_, units)| units);
          let text: String = char::decode_utf16(units.iter().copied())
              .map(|c| c.unwrap_or(char::REPLACEMENT_CHARACTER))
              .collect();
          let ranges = thaiwrap_core::wrap(&text, max_length, options).map_err(|e| core_error(env, &e))?;
          let offsets = utf16_offsets(&text, &ranges)?;
          offsets
              .as_chunks::<2>()
              .0
              .iter()
              .map(|&[start, end]| {
                  units
                      .get(start as usize..end as usize)
                      .map(|line| Utf16String::from(line.to_vec()))
                      .ok_or_else(|| internal_error("a line is out of bounds"))
              })
              .collect()
      }

      fn internal_error(what: &str) -> Error {
          Error::new(Status::GenericFailure, format!("thaiwrap internal error: {what}"))
      }
      ```
