**Goal:** Build and ship-ready v0.1 of `thaiwrap`, a Rust Node-API addon that wraps Thai text at word boundaries, with tests, benchmarks, CI, and a token-free release pipeline, stopping before the first npm publish.
**Architecture:** A pure Rust core crate (`thaiwrap-core`) segments text with ICU4X, filters break positions through the Thai text rules, and fills lines greedily, returning byte ranges.
A thin napi-rs binding crate (`thaiwrap-node`) validates JS arguments and converts types; a small hand-written `index.js` wraps the napi-rs generated loader to explain load failures.
GitHub Actions build six prebuilt targets, run the tests on Node 22, Node 24, and the latest Bun, and publish through release-please and npm trusted publishing.
**Tech Stack:** Rust (edition 2021, MSRV 1.88), `icu_segmenter =2.4.0` (compiled data), napi 3 / napi-derive 3.7 / napi-build 2, `@napi-rs/cli` 3.10.9, proptest, criterion, mitata, Bun, Node 22/24, GitHub Actions, release-please, npm trusted publishing.

**NOT building:**

| # | Decision |
|---|---|
| D1 | JS API: `wrapThai(text: string, maxLength: number, options?: WrapOptions): string[]` with `WrapOptions { measure?: 'codeUnits' \| 'graphemes'; overflow?: 'split' \| 'keep' }`. Defaults `measure: "codeUnits"`, `overflow: "split"`. |
| D2 | Length is UTF-16 code units by default; `graphemes` is opt-in; no visual-width measure in v0.1. |
| D3 | Greedy first-fit line filling. Minimum raggedness would fail the acceptance test. |
| D4 | Break positions come from `WordSegmenter::new_dictionary` in v0.1. Switching to the UAX #14 `LineSegmenter` happens only after the M0.2 comparison (Task 11) and the user's recorded approval (Task 21). The comparison is strict on raw boundaries and reports two groups: (a) differences the post-filter removes (the break-space, no-break, or Thai rules inside `allowed`, labelled which), (b) differences that remain after it. The user decides on both; (b) blocks the switch until approved. |
| D5 | Every candidate break, from the segmenter and from overflow splitting, passes one Thai rule filter (`allowed`): AGENTS.md Thai rules 1-3. |
| D6 | Overflow default `split`: every line fits `maxLength`. Splits happen only at grapheme boundaries that pass the Thai filter. Exactly one unit that cannot be split under those rules may exceed `maxLength`, alone on its line. No RangeError for this. `keep` is opt-in. README recommends `maxLength >= 5` for Thai. |
| D7 | Whitespace: trim break spaces at line edges; keep interior spaces as written (no collapsing). ZWSP (U+200B) counts as a break space; NBSP, U+2007, U+202F never break and are not trimmed inside text. `allowed` enforces "never break" by rejecting any position directly next to NBSP, U+2007, U+202F, WORD JOINER U+2060, or U+FEFF. |
| D8 | Hard breaks: LF, CR, CRLF, VT, FF, NEL, U+2028, U+2029 always end a line (the UAX #14 mandatory breaks). A final line break does not add an empty line, the way Python `str.splitlines()` treats it; unlike Python, U+001C-U+001E are not breaks. |
| D9 | Blank lines: an input line (paragraph) with no visible characters (all `White_Space` or ZWSP) becomes `""`. A soft-wrapped piece with no visible characters (for example a lone NBSP between spaces) is dropped, so `""` never appears inside one paragraph (proposed in review round 2; awaiting the user's confirmation). Side effect: only a paragraph's first piece can be dropped, and the result depends on `maxLength`: `"\u00A0 ก"` gives `["ก"]` at max 2 and `["\u00A0 ก"]` at max 3. `is_visible` follows the definition above (not `White_Space`, not ZWSP), so U+FEFF, U+2060, U+00AD, LRM/RLM count as visible. Blank lines before the first and after the last line with visible content are dropped; blank lines between them are kept as-is, not collapsed. Input with no visible characters returns `[]`. No option in v0.1. A later option, if users ask, is `blankLines: "preserve" \| "collapse" \| "trim"`. |
| D10 | Lone surrogates: v0.1 replaces them with U+FFFD (napi UTF-8 conversion), documented in README as a known limitation. Preserving them arrives with the UTF-16 path and is recorded in the changelog. |
| D11 | Invalid arguments: wrong types throw `TypeError`, wrong values throw `RangeError`, with messages written for JS users. Nothing panics across FFI. |
| D12 | Targets v0.1: linux-x64-gnu, linux-arm64-gnu, linux-x64-musl, darwin-arm64, darwin-x64, win32-x64-msvc. Unsupported platforms get an error naming the platform. |

## Global Constraints

- Acceptance test, never weakened: `wrapThai("กระบวนการสื่อสาร ส่งมอบ และสร้างคุณค่า", 10)` returns `["กระบวนการ", "สื่อสาร", "ส่งมอบ และ", "สร้าง", "คุณค่า"]` in `cargo test` and in the JS tests on Node and Bun (AGENTS.md:16, AGENTS.md:128).
- Thai rules (AGENTS.md:118-123): never start a line with a combining mark (U+0E31, U+0E34-U+0E3A, U+0E47-U+0E4E); never end a line with a leading vowel (U+0E40-U+0E44); never start a line with ะ า ำ ๆ ฯ (U+0E30, U+0E32, U+0E33, U+0E46, U+0E2F). These apply to every line start or end created by a soft break; the input's own first character of a paragraph is kept as written.
- Rust: stable toolchain pinned in `rust-toolchain.toml`; edition 2021; `rust-version = "1.88"` (the MSRV of both `icu_segmenter` 2.4 and `napi` 3); commit `Cargo.lock`.
- `thaiwrap-core/src/lib.rs` starts with `#![forbid(unsafe_code)]`, `#![deny(missing_docs)]`, `#![warn(clippy::pedantic)]`. "Allow individual pedantic lints locally with `#[allow(clippy::...)]` and a one-line comment saying why. Never blanket-allow at crate level." (AGENTS.md:62-70, verbatim; AGENTS.md wins over the repo skill's `#[expect]` advice.) The binding crate does not enable pedantic lints.
- No `unsafe` in hand-written code anywhere. The binding crate cannot use `#![forbid(unsafe_code)]` because `#[napi]` expands to unsafe FFI glue; CI enforces the rule with `! grep -rnw "unsafe" crates/*/src`.
- No `unwrap()`, `expect()`, `panic!`, `unreachable!`, or out-of-bounds indexing in library code; slice strings only with `str::get` at segmenter or `char_indices` boundaries; use saturating arithmetic for lengths (AGENTS.md:74-78). Tests and benches may `unwrap()`.
- Core errors: `Result<_, WrapError>` with hand-written `Display` and `Error`; no `thiserror`, no `anyhow` (AGENTS.md:82-84; this overrides the repo skill's thiserror advice).
- Core API returns `Vec<Range<usize>>` byte ranges; owned `Vec<String>` exists only in the binding (AGENTS.md:88).
- `WrapOptions`, `Measure`, `Overflow`, `WrapError` are `#[non_exhaustive]`; external crates (including `tests/` and `benches/`) build options with `let mut o = WrapOptions::default(); o.measure = Measure::Graphemes;`, never a struct literal.
- Segmenters are built once: `OnceLock` for `WordSegmenter`/`LineSegmenter`, a `static` for the `const fn` `GraphemeClusterSegmenter::new()` (AGENTS.md:95).
- Release profile in the workspace root: `lto = true`, `codegen-units = 1`, `strip = true`, `opt-level = 3`; `panic` stays `unwind` (AGENTS.md:99).

- Dependencies are exactly those in D15. Pin `icu_segmenter = "=2.4.0"` with `default-features = false, features = ["compiled_data"]`. Pin `@napi-rs/cli` to `3.10.9`. Any other dependency is a STOP-and-ask.

### Error handling
No existing pattern - establishing new convention: core `WrapError` enum with hand-written `Display`; binding maps to JS error classes.
<!-- SOURCE: AGENTS.md:82-84 -->
```text
- The core returns `Result<T, WrapError>`, where `WrapError` is an enum with one variant per failure (for example `InvalidMaxLength`).
- Implement `std::error::Error` and `Display` by hand. Do not add `thiserror` or `anyhow` to the core; keep it dependency-light.
- The binding maps errors to JS: invalid types become `TypeError`, invalid values become `RangeError`. Error messages are written for JS users, not Rust users.
```

### Tests
No existing pattern - establishing new convention: unit tests in `#[cfg(test)] mod tests` beside the code; integration tests in `crates/thaiwrap-core/tests/`; JS cases shared by a Bun runner and a Node runner.
<!-- SOURCE: AGENTS.md:127-128 -->
```text
- **Unit tests** live next to the code in `#[cfg(test)] mod tests`.
- **The acceptance test** exists in both `cargo test` and `bun test`. Never delete or weaken it.
```

### Comments
Thai-specific rules always get a comment with an example, because most readers cannot read Thai.

  ```rust
  //! Where a line may break, by the Thai text rules in AGENTS.md.

  /// Thai vowels and tone marks written above or below a consonant (U+0E31, U+0E34-U+0E3A,
  /// U+0E47-U+0E4E). A line must not start with one: "ื่อสาร" is the broken tail of "สื่อสาร".
  pub(crate) fn is_combining_mark(c: char) -> bool {
      matches!(c, '\u{0E31}' | '\u{0E34}'..='\u{0E3A}' | '\u{0E47}'..='\u{0E4E}')
  }

  /// Leading vowels เ แ โ ใ ไ (U+0E40-U+0E44) are written before the consonant they are
  /// pronounced after, so they belong to the next character: "เก" must not end a line after "เ".
  pub(crate) fn is_leading_vowel(c: char) -> bool {
      matches!(c, '\u{0E40}'..='\u{0E44}')
  }

  /// ะ า ำ ๆ ฯ attach to what comes before them, so they must not start a line:
  /// "กา" must not become "ก" + "า", and "ดี ๆ" must not put "ๆ" on the next line.
  pub(crate) fn is_no_line_start(c: char) -> bool {
      matches!(c, '\u{0E30}' | '\u{0E32}' | '\u{0E33}' | '\u{0E46}' | '\u{0E2F}')
  }

  /// Spaces that separate words and are trimmed at line edges. ZWSP (U+200B) is one even
  /// though it is not `White_Space`; Thai web text uses it as an invisible word separator.
  /// No-break spaces (U+00A0, U+2007, U+202F) are content, not break opportunities.
  pub(crate) fn is_break_space(c: char) -> bool {
      c == '\u{200B}' || (c.is_whitespace() && !matches!(c, '\u{00A0}' | '\u{2007}' | '\u{202F}'))
  }

  /// A character that shows up on screen. A line without one is a blank line.
  pub(crate) fn is_visible(c: char) -> bool {
      !(c.is_whitespace() || c == '\u{200B}')
  }

  /// No-break spaces and joiners glue their neighbours together: "100\u{00A0}บาท" must stay on
  /// one line. The word segmenter reports a boundary on both sides of them, so the rule has to
  /// live here, where both segmenter breaks and overflow cuts are checked.
  fn is_no_break(c: char) -> bool {
      matches!(c, '\u{00A0}' | '\u{2007}' | '\u{202F}' | '\u{2060}' | '\u{FEFF}')
  }

  /// True if a line may break at byte `pos` of the paragraph `para`.
  ///
  /// The Thai checks look past break spaces, because spaces at a break are trimmed: in "ดี ๆ"
  /// a break after the space would still start the next line with "ๆ".
  pub(crate) fn allowed(para: &str, pos: usize) -> bool {
      let (Some(before), Some(after)) = (para.get(..pos), para.get(pos..)) else {
          return false;
      };
      // A break always sits after the spaces, never before them, so neither a segmenter break
      // nor an overflow cut can start a line with a space ("ส่งมอบ| และ" is rejected).
      if after.chars().next().is_some_and(is_break_space) {
          return false;
      }
      if before.chars().next_back().is_some_and(is_no_break) || after.chars().next().is_some_and(is_no_break) {
          return false;
      }
      let prev = before.chars().rev().find(|&c| !is_break_space(c));
      let next = after.chars().find(|&c| !is_break_space(c));
      match (prev, next) {
          (Some(prev), Some(next)) => {
              !(is_combining_mark(next) || is_no_line_start(next) || is_leading_vowel(prev))
          }
          // A paragraph edge is not a soft break.
          _ => true,
      }
  }
  ```

  ```rust
  //! Splitting text at hard line breaks.
  use std::ops::Range;

  /// The mandatory breaks of UAX #14 (BK, CR, LF, NL). CRLF counts as one break.
  fn is_hard_break(c: char) -> bool {
      matches!(c, '\n' | '\u{000B}' | '\u{000C}' | '\r' | '\u{0085}' | '\u{2028}' | '\u{2029}')
  }

  /// Paragraph ranges. A final break adds no empty line: `""` gives none, `"a\n"` gives one,
  /// `"a\n\nb"` gives three (the middle one empty).
  pub(crate) fn split_lines(text: &str) -> impl Iterator<Item = Range<usize>> + '_ {
      let mut chars = text.char_indices().peekable();
      let mut start = 0;
      std::iter::from_fn(move || {
          while let Some((i, c)) = chars.next() {
              if is_hard_break(c) {
                  let line = start..i;
                  start = i + c.len_utf8();
                  if c == '\r' && chars.next_if(|&(_, next)| next == '\n').is_some() {
                      start += 1;
                  }
                  return Some(line);
              }
          }
          (start < text.len()).then(|| {
              let line = start..text.len();
              start = text.len();
              line
          })
      })
  }
  ```

  ```rust
  use std::ops::Range;
  use std::sync::OnceLock;

  use icu_segmenter::options::WordBreakInvariantOptions;
  use icu_segmenter::{GraphemeClusterSegmenter, GraphemeClusterSegmenterBorrowed, WordSegmenter, WordSegmenterBorrowed};

  use crate::thai;

  static GRAPHEMES: GraphemeClusterSegmenterBorrowed<'static> = GraphemeClusterSegmenter::new();

  fn word_segmenter() -> &'static WordSegmenterBorrowed<'static> {
      static SEGMENTER: OnceLock<WordSegmenterBorrowed<'static>> = OnceLock::new();
      SEGMENTER.get_or_init(|| WordSegmenter::new_dictionary(WordBreakInvariantOptions::default()))
  }

  /// Byte offsets inside `para` where the segmenter allows a break, without 0 and `para.len()`.
  /// The word segmenter reports "ส่งมอบ| |และ"; `thai::allowed` later drops the offset before the
  /// space, so the word and line segmenters (which never break before a space) give the same units.
  pub(crate) fn break_candidates(para: &str) -> impl Iterator<Item = usize> + '_ {
      word_segmenter().segment_str(para).filter(move |&b| b > 0 && b < para.len())
  }

  /// Grapheme cluster boundaries of `s`, including 0 and `s.len()`.
  pub(crate) fn grapheme_boundaries(s: &str) -> impl Iterator<Item = usize> + '_ {
      GRAPHEMES.segment_str(s)
  }

  /// Text between two allowed breaks: visible content plus the break spaces after it.
  #[derive(Debug, Clone, PartialEq, Eq)]
  pub(crate) struct Unit {
      pub(crate) content: Range<usize>,
      pub(crate) trailing: Range<usize>,
  }

  /// The units of a paragraph, in order. Only the first unit can have empty content
  /// (when the paragraph starts with spaces).
  pub(crate) fn units(para: &str) -> impl Iterator<Item = Unit> + '_ {
      let mut ends = break_candidates(para)
          .filter(move |&b| thai::allowed(para, b))
          .chain(std::iter::once(para.len()));
      let mut start = 0;
      std::iter::from_fn(move || {
          let end = ends.next()?;
          let unit = unit(para, start..end);
          start = end;
          Some(unit)
      })
  ```

  //! Greedy line filling.
  use std::ops::Range;

  use crate::measure::measure;
  use crate::{lines, segment, thai, Overflow, WrapError, WrapOptions};

  /// Wrap `text` into lines of at most `max_length`, breaking only where the segmenter
  /// and the Thai text rules allow.
  ///
  /// Returns byte ranges into `text`, in order. An empty range is a blank line.
  /// A line is longer than `max_length` only when it holds one unit that cannot be split
  /// (for example "ที่", one grapheme of 3 code units, with `max_length` 1), or one word with
  /// [`Overflow::Keep`].
  ///
  /// ```
  /// use thaiwrap_core::{wrap, WrapOptions};
  /// let text = "กระบวนการสื่อสาร ส่งมอบ และสร้างคุณค่า";
  /// let lines: Vec<&str> = wrap(text, 10, &WrapOptions::default())?
  ///     .into_iter()
  ///     .filter_map(|r| text.get(r))
  ///     .collect();
  /// assert_eq!(lines, ["กระบวนการ", "สื่อสาร", "ส่งมอบ และ", "สร้าง", "คุณค่า"]);
  /// # Ok::<(), thaiwrap_core::WrapError>(())
  /// ```
  ///
  /// # Errors
  ///
  /// [`WrapError::InvalidMaxLength`] if `max_length` is 0.
  pub fn wrap(text: &str, max_length: usize, options: &WrapOptions) -> Result<Vec<Range<usize>>, WrapError> {
      if max_length == 0 {
          return Err(WrapError::InvalidMaxLength);
      }
      let mut out = Vec::new();
      for para in lines::split_lines(text) {
          let before = out.len();
          if let Some(para_text) = text.get(para.clone()) {
              Paragraph { text: para_text, base: para.start, max_length, options, out: &mut out }.wrap();
          }
          if out.len() == before {
              out.push(para.start..para.start);
          }
      }
      drop_blank_edges(&mut out);
      Ok(out)
  }

  /// Blank lines before the first and after the last visible line are dropped; the ones
  /// between visible lines stay. So "\n\nก\n\n" gives ["ก"] and "   " gives [].
  fn drop_blank_edges(out: &mut Vec<Range<usize>>) {
      let first = out.iter().position(|r| !r.is_empty()).unwrap_or(out.len());
      out.drain(..first);
      let end = out.iter().rposition(|r| !r.is_empty()).map_or(0, |i| i + 1);
      out.truncate(end);
  }

  struct Line {
      range: Range<usize>,
      len: usize,
  }

  struct Paragraph<'a> {
      text: &'a str,
      base: usize,
      max_length: usize,
      options: &'a WrapOptions,
      out: &'a mut Vec<Range<usize>>,
  }

  impl Paragraph<'_> {
      fn wrap(mut self) {
          let text = self.text;
          let mut line: Option<Line> = None;
          let mut gap = 0;
          for unit in segment::units(text) {
              if unit.content.is_empty() {
                  continue;
              }
              let width = self.measure(unit.content.clone());
              line = Some(match line.take() {
                  Some(mut current) if current.len.saturating_add(gap).saturating_add(width) <= self.max_length => {
                      current.range.end = unit.content.end;
                      current.len = current.len.saturating_add(gap).saturating_add(width);
                      current
                  }
                  Some(current) => {
                      self.push(current.range);
                      self.start_line(unit.content, width)
                  }
                  None => self.start_line(unit.content, width),
              });
              gap = self.measure(unit.trailing);
          }
          if let Some(current) = line {
              self.push(current.range);
          }
      }

      fn start_line(&mut self, content: Range<usize>, width: usize) -> Line {
          if width <= self.max_length || self.options.overflow == Overflow::Keep {
              return Line { range: content, len: width };
          }
          let mut chunks = self.split_overflow(content.clone());
          let last = chunks.pop().unwrap_or(Line { range: content, len: width });
          for chunk in chunks {
              self.push(chunk.range);
          }
          last
      }

      /// Cut one too-long unit at grapheme boundaries that pass the Thai rules, greedily.
      /// A piece with no legal cut inside stays whole, even if it is longer than `max_length`.
      fn split_overflow(&self, content: Range<usize>) -> Vec<Line> {
          let text = self.text;
          let Some(word) = text.get(content.clone()) else {
              return Vec::new();
          };
          let cuts = segment::grapheme_boundaries(word)
              .map(|b| content.start + b)
              .filter(|&b| b > content.start && b < content.end && thai::allowed(text, b))
              .chain(std::iter::once(content.end));
          let mut chunks: Vec<Line> = Vec::new();
          let mut piece_start = content.start;
          for cut in cuts {
              let width = self.measure(piece_start..cut);
              match chunks.last_mut() {
                  Some(chunk) if chunk.len.saturating_add(width) <= self.max_length => {
                      chunk.range.end = cut;
                      chunk.len = chunk.len.saturating_add(width);
                  }
                  _ => chunks.push(Line { range: piece_start..cut, len: width }),
              }
              piece_start = cut;
          }
          chunks
      }

      fn measure(&self, range: Range<usize>) -> usize {
          measure(self.text.get(range).unwrap_or_default(), self.options.measure)
      }

      /// Trims break spaces from both ends (an overflow cut can leave one at an edge, for
      /// example after a space that is followed by a soft hyphen), and drops a soft-wrapped
      /// line with no visible character (for example only NBSP).
      /// Blank output lines come only from blank input lines, which `wrap` adds per paragraph.
      fn push(&mut self, range: Range<usize>) {
          let Some(line) = self.text.get(range.clone()) else {
              return;
          };
          let trimmed = line.trim_matches(thai::is_break_space);
          if trimmed.chars().any(thai::is_visible) {
              let start = range.start + (line.len() - line.trim_start_matches(thai::is_break_space).len());
              self.out.push(self.base + start..self.base + start + trimmed.len());
          }
      }
  }

  ```rust
  //! Node-API binding for thaiwrap-core: converts JS values, validates them, maps errors.
  use napi::bindgen_prelude::*;
  use napi_derive::napi;
  use thaiwrap_core::{Measure, Overflow};

  /// Options for `wrapThai`. Every field is optional.
  #[napi(object)]
  pub struct WrapOptions {
      /// How line length is counted. Default `"codeUnits"` (the same as `String.prototype.length`).
      #[napi(ts_type = "'codeUnits' | 'graphemes'")]
      pub measure: Option<String>,
      /// What to do with a single word longer than `maxLength`. Default `"split"`.
      #[napi(ts_type = "'split' | 'keep'")]
      pub overflow: Option<String>,
  }

  /// Wrap text into lines of at most `maxLength`, breaking between words.
  /// A word longer than `maxLength` is cut only where Thai rules allow (or kept whole with
  /// `overflow: "keep"`), and no line starts with a Thai vowel or tone mark.
  /// @throws {TypeError} if `text` is not a string, `maxLength` is not a number, or `options` has a wrong type.
  /// @throws {RangeError} if `maxLength` is not a positive safe integer, or an option has an unknown value.
  #[napi(
      catch_unwind,
      ts_args_type = "text: string, maxLength: number, options?: WrapOptions | undefined | null"
  )]
  pub fn wrap_thai(env: Env, text: Unknown<'_>, max_length: Unknown<'_>, options: Option<Unknown<'_>>) -> Result<Vec<String>> {
      let text = read_string(&env, &text, "text")?;
      let max_length = read_max_length(&env, &max_length)?;
      let options = to_core_options(&env, read_options(&env, options.as_ref())?)?;
      let ranges = thaiwrap_core::wrap(&text, max_length, &options).map_err(|e| range_error(&env, &e.to_string()))?;
      ranges
          .into_iter()
          .map(|r| {
              text.get(r).map(str::to_owned).ok_or_else(|| {
                  Error::new(Status::GenericFailure, "thaiwrap internal error: a line does not end on a character boundary")
              })
          })
          .collect()
  }

  const MAX_SAFE_INTEGER: f64 = 9_007_199_254_740_991.0;

  fn read_string(env: &Env, value: &Unknown<'_>, name: &str) -> Result<String> {
      if value.get_type()? != ValueType::String {
          return Err(type_error(env, &format!("{name} must be a string, got {}", type_name(value))));
      }
      // Lossy on purpose: lone surrogates become U+FFFD (D10), whatever bytes the runtime's
      // napi_get_value_string_utf8 produces for them (V8 and Bun differ).
      let utf8 = value.coerce_to_string()?.into_utf8()?;
      Ok(String::from_utf8_lossy(utf8.as_slice()).into_owned())
  }

  fn read_max_length(env: &Env, value: &Unknown<'_>) -> Result<usize> {
      if value.get_type()? != ValueType::Number {
          return Err(type_error(env, &format!("maxLength must be a number, got {}", type_name(value))));
      }
      let n = value.coerce_to_number()?.get_double()?;
      max_length_from_f64(n)
          .ok_or_else(|| range_error(env, &format!("maxLength must be a positive integer, got {}", js_number(n))))
  }

  fn max_length_from_f64(n: f64) -> Option<usize> {
      if !(n.is_finite() && n.fract() == 0.0 && (1.0..=MAX_SAFE_INTEGER).contains(&n)) {
          return None;
      }
      // n is an integer in 1..=2^53-1, so the cast to u64 is exact.
      let n = n as u64;
      Some(usize::try_from(n).unwrap_or(usize::MAX))
  }

  /// Formats a number the way JS prints it in the cases we report (NaN, Infinity, integers, decimals).
  fn js_number(n: f64) -> String {
      if n.is_nan() {
          "NaN".to_owned()
      } else if n.is_infinite() {
          if n > 0.0 { "Infinity" } else { "-Infinity" }.to_owned()
      } else {
          n.to_string()
      }
  }

  fn read_options(env: &Env, value: Option<&Unknown<'_>>) -> Result<WrapOptions> {
      let empty = WrapOptions { measure: None, overflow: None };
      let Some(value) = value else { return Ok(empty) };
      match value.get_type()? {
          ValueType::Undefined | ValueType::Null => return Ok(empty),
          ValueType::Object => {}
          _ => return Err(type_error(env, &format!("options must be an object, got {}", type_name(value)))),
      }
      let object = value.coerce_to_object()?;
      Ok(WrapOptions {
          measure: read_option(env, &object, "measure")?,
          overflow: read_option(env, &object, "overflow")?,
      })
  }

  fn read_option(env: &Env, object: &Object<'_>, key: &str) -> Result<Option<String>> {
      let value: Unknown<'_> = object.get_named_property(key)?;
      match value.get_type()? {
          ValueType::Undefined => Ok(None),
          _ => read_string(env, &value, &format!("options.{key}")).map(Some),
      }
  }

  fn to_core_options(env: &Env, options: WrapOptions) -> Result<thaiwrap_core::WrapOptions> {
      let mut core = thaiwrap_core::WrapOptions::default();
      if let Some(value) = options.measure {
          core.measure = match value.as_str() {
              "codeUnits" => Measure::CodeUnits,
              "graphemes" => Measure::Graphemes,
              // {value:?} prints the value quoted and escapes NUL, which CString (used by throw_range_error) rejects.
              _ => return Err(range_error(env, &format!(r#"options.measure must be "codeUnits" or "graphemes", got {value:?}"#))),
          };
      }
      if let Some(value) = options.overflow {
          core.overflow = match value.as_str() {
              "split" => Overflow::Split,
              "keep" => Overflow::Keep,
              _ => return Err(range_error(env, &format!(r#"options.overflow must be "split" or "keep", got {value:?}"#))),
          };
      }
      Ok(core)
  }

  fn type_name(value: &Unknown<'_>) -> &'static str {
      match value.get_type() {
          Ok(ValueType::Undefined) => "undefined",
          Ok(ValueType::Null) => "null",
          Ok(ValueType::Boolean) => "boolean",
          Ok(ValueType::Number) => "number",
          Ok(ValueType::String) => "string",
          Ok(ValueType::Symbol) => "symbol",
          Ok(ValueType::Object) => "object",
          Ok(ValueType::Function) => "function",
          // ValueType::BigInt exists only with the napi6 feature; napi4 reports BigInt as Unknown.
          _ => "an unsupported value",
      }
  }

  // env.throw_* sets a pending JS exception; returning PendingException tells napi-rs not to
  // throw a second (plain Error) on top of it.
  fn type_error(env: &Env, message: &str) -> Error {
      match env.throw_type_error(message, None) {
          Ok(()) => Error::from_status(Status::PendingException),
          Err(e) => e,
      }
  }

  fn range_error(env: &Env, message: &str) -> Error {
      match env.throw_range_error(message, None) {
          Ok(()) => Error::from_status(Status::PendingException),
          Err(e) => e,
      }
  }
  ```

  ```js
  'use strict'
  const { napi } = require('./package.json')

  const ARCH = { x86_64: 'x64', aarch64: 'arm64' }
  const OS = { linux: 'linux', darwin: 'darwin', windows: 'win32' }

  // The names napi-rs uses for npm/<dir>: "x86_64-unknown-linux-gnu" -> "linux-x64-gnu",
  // "aarch64-apple-darwin" -> "darwin-arm64", "x86_64-pc-windows-msvc" -> "win32-x64-msvc".
  function platformName(triple) {
    const [arch, , os, abi] = triple.split('-')
    return [OS[os], ARCH[arch], abi].filter(Boolean).join('-')

  function currentPlatform() {

      // Same detection as the generated loader: skip the slow network part of the report.
      if (process.report) process.report.excludeNetwork = true

    if (platform === 'win32') return `win32-${arch}-msvc`
    return `${platform}-${arch}`

    return napi.targets.map(platformName)

      : `thaiwrap has no prebuilt binary for ${current}. Supported: ${supported.join(', ')}.`
    return new Error(message, { cause })
  }
  ```

  ```js
  const words = new Intl.Segmenter('th', { granularity: 'word' })
  const graphemes = new Intl.Segmenter('th', { granularity: 'grapheme' })
  const HARD_BREAK = /\r\n|[\n\v\f\r\u0085\u2028\u2029]/
  const isMark = (c) => /[\u0E31\u0E34-\u0E3A\u0E47-\u0E4E]/.test(c)
  const isLeading = (c) => /[\u0E40-\u0E44]/.test(c)
  const isNoStart = (c) => /[\u0E30\u0E32\u0E33\u0E46\u0E2F]/.test(c)
  const isBreakSpace = (c) => c === '\u200B' || (/\p{White_Space}/u.test(c) && !/[\u00A0\u2007\u202F]/.test(c))
  const isVisible = (c) => !(c === '\u200B' || /\p{White_Space}/u.test(c))
  const len = (s, measure) => (measure === 'graphemes' ? [...graphemes.segment(s)].length : s.length)

  const isNoBreak = (c) => /[\u00A0\u2007\u202F\u2060\uFEFF]/.test(c ?? '')

  function allowed(para, pos) {
    if (pos < para.length && isBreakSpace(para[pos])) return false
    if (isNoBreak(para[pos - 1]) || isNoBreak(para[pos])) return false
    let i = pos - 1
    while (i >= 0 && isBreakSpace(para[i])) i--
    let j = pos
    while (j < para.length && isBreakSpace(para[j])) j++
    if (i < 0 || j >= para.length) return true
    return !(isMark(para[j]) || isNoStart(para[j]) || isLeading(para[i]))
  }

  function trimBreakSpaces(s) {
    let a = 0, b = s.length
    while (a < b && isBreakSpace(s[a])) a++
    while (b > a && isBreakSpace(s[b - 1])) b--
    return [s.slice(a, b), s.slice(b)]
  }

  function splitOverflow(word, max, measure) {
    const cuts = [...graphemes.segment(word)].map((g) => g.index).filter((i) => i > 0 && allowed(word, i))
    cuts.push(word.length)
    const chunks = []
    let start = 0
    for (const cut of cuts) {
      const piece = word.slice(start, cut)
      const w = len(piece, measure)
      const last = chunks.at(-1)
      if (last && last.len + w <= max) { last.text += piece; last.len += w } else chunks.push({ text: piece, len: w })
      start = cut
    }
    return chunks
  }

  function wrapParagraph(para, max, measure, overflow, out) {
    const push = (s) => {
      const [content] = trimBreakSpaces(s)
      if ([...content].some(isVisible)) out.push(content)
    }
    const ends = []
    for (const { index } of words.segment(para)) if (index > 0 && allowed(para, index)) ends.push(index)
    ends.push(para.length)
    let start = 0, line = null, gap = ''
    for (const end of ends) {
      const [content, trailing] = trimBreakSpaces(para.slice(start, end))
      start = end
      if (!content) continue
      const w = len(content, measure)
      if (line && line.len + len(gap, measure) + w <= max) {
        line.text += gap + content
        line.len += len(gap, measure) + w
      } else {
        if (line) push(line.text)
        if (w > max && overflow === 'split') {
          const chunks = splitOverflow(content, max, measure)
          line = chunks.pop()
          for (const c of chunks) push(c.text)
        } else line = { text: content, len: w }
      }
      gap = trailing
    }
    if (line) push(line.text)
  }

  export function wrapReference(text, maxLength, { measure = 'codeUnits', overflow = 'split' } = {}) {
    const paras = text.split(HARD_BREAK)
    if (paras.at(-1) === '') paras.pop()
    const out = []
    for (const para of paras) {
      const before = out.length
      wrapParagraph(para, maxLength, measure, overflow, out)
      if (out.length === before) out.push('')
    }
    while (out[0] === '') out.shift()
    while (out.at(-1) === '') out.pop()
    return out
  }
  ```
